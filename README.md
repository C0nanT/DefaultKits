# DefaultKits

Sistema de kits para servidor Hytale. Oferece comandos de kits que configuram o estilo de jogo do jogador (itens, bônus e comportamentos específicos).

## Instalação

1. Baixe o arquivo `DefaultKits.jar` na aba [Releases](../../releases)
2. Copie para a pasta `mods` do seu servidor Hytale
3. Reinicie o servidor

## Requisitos

- Servidor Hytale com Java 21+

## Recursos

### Kit Archer
Ative com o comando `/kit archer` para:
- Receber arco, flechas e equipamentos leves
- Causar dano aumentado com arco/flecha
- Ganhar +2 flechas ao acertar alvos válidos

## Uso

```
/kit archer    # Ativa o kit archer
```

## Roadmap
